# Tutorial Case Canted-Valves Engines
## Prerequisites
Compile modified `fvMotionSolverEngineMesh` (`$FOAM_SRC/engine/engineMesh`) using `wmake`.

## Background
3D motion is build on top of uni-directional engine motion (`engineMesh`+ `dynamicMesh`). Tested with v2206 ... v2512.

## Run
Run `Allrun` script
